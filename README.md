# Sowee

Compliant invoice financing on-chain: an unpaid invoice becomes a KYC-gated,
fractional bond token that is priced by a signed discount quote, funded in USDC,
tradable on a compliant secondary market, and settled pro-rata at maturity.

Built from scratch for [ETHOnline 2026](https://ethglobal.com/events/ethonline2026)
(hacking window 4–13 September 2026). Nothing in this repository predates the window.

Status: scaffold. See issues and pull requests for progress.
